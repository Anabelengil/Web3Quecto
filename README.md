# Web3Quecto

Web3Quecto enables autonomous, decentralized off-chain processing of smart contract transactions through a secure, modular gateway framework.

The key benefits of using Web3Quecto include:

- Web3Quecto enables autonomous, decentralized off-chain
- processing of smart contract transactions
- through a secure, modular gateway

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Quecto.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
